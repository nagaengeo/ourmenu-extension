# ourMenu(-extension)
실시간 결제 데이터 기반의 숭실대 학식 정보 공유 플랫폼, OurMenu
기존 숭실대 학식 앱의 한계를 분석하고, 불필요한 커뮤니티 기능을 배제하여 실시간 정보의 정확도와 결제 기반의 신뢰도에 집중한 프로젝트입니다.

## 사용자 경험 및 타겟 사용자
실시간 소통 부재로 인한 메뉴 품절, 대기 시간, 정보 혼선으로 인한 불편을 막고자 시간이 소중한 모든 학생을 대상

## OurMenu만의 차별점
1. 메뉴 기획 및 품질 개선
   - 데이터 통계를 이용한 인기 메뉴 확보 가능
   - 향후 메뉴 개발 및 기존 메뉴의 품질 개선에 도움
   - 수요 예측을 통한 쓰레기 절감 및 식자재 비용 절감
2. 학식 이용률 및 매출 등대
   - 인스타로만 확인 가능했던 특식에 대한 공지 등 학교 측은 학식에 대한 홍보를 쉽게 제공 (접근성 향상)
3. 주 소비자 시점에서 공감대 형성
   - 실시간 정보 공유 기능으로 학생들의 시간 낭비를 원천 차단하여 공익적 도움
   - 합리적인 소비 유도, 의견을 모으는 창구 역할

## Core Features
1. 사용자 인증 및 관리
   - 파이어베이스 이메일 인증을 통해 1인 1계정 체제를 유지하며 서비스 신뢰도를 확보
   - 마이페이지에서 본인이 식권 스캔 후 작성한 '실구매 인증 리뷰' 목록을 확인하고 관리
2. 실시간 식단 및 공지사항 큐레이션
   - <soongguri.com>에서 메뉴명, 가격, 음식 사진 URL을 실시간 파싱하여 정보를 제공
   - 홈 화면 상단 알림 아이콘을 통해 조기 마감, 메뉴 변경 등 크롤링된 공지를 즉시 공유
   - 캘린더 피커를 통해 특정 날짜의 메뉴를 미리 확인할 수 있는 편의성을 제공
3. 결제 기반 신뢰 리뷰
   - Google ML Kit로 식권 QR코드를 스캔하여 실제 결제가 완료된 사용자에게만 리뷰 작성 권한을 부여
   - 댓글 기능을 삭제하고, 메뉴에 대한 순수 별점 및 후기 데이터만 수집
4. 실시간 식당 혼잡도 분석
   - 최근 30분간의 실시간 결제 성공 횟수를 기반으로 식당의 혼잡도를 자동 산출하여 제공
   - 결제 발생 시마다 DB의 메뉴 잔여 수량을 자동 차감하여 실시간 품절 여부를 공유
5. 학생 참여형 식단 반영
   - 매달 선호도가 높았던 메뉴를 대상으로 재출시 투표를 진행
   - 특정 득표수 달성 시 다음 달 식단에 해당 메뉴가 우선 배치되도록 제안하는 소통 창구 역할을 수행
